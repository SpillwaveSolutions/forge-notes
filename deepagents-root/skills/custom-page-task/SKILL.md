# Custom page task

## Steps
1. Read the custom instruction carefully.
2. Use page title + body as source material.
3. Prefer multi-block structured output (`blocks`) when the result is multi-section.
4. Use `text` only for a single prose answer.

## Rules
- Stay on-task; do not lecture about how AI works.
- Allowed block types only.
- If instruction is vague, produce a short outline of what you can do + first useful draft.
